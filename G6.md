# Availability, Limitations, Ethics, and Societal Impact

## Availability

This product uses publicly accessible Seattle data to explore park features across the city. The data supporting this project is available through the original public web sources and the local project files used for analysis. Any cleaned or combined datasets created during the project should be included with the final submission so that others can inspect, reproduce, or reuse the workflow.

This product considers **FAIR principles and portability** by using common formats like JSON, CSV, and HTML. These formats make the data easier to find, access, connect across sources through shared park IDs, and reuse with proper documentation. Portability is supported because the data can be moved into different tools or workflows without depending on one platform or technology.

## Limitations

The product simplifies Seattle Parks information and **is meant for educational and informational purposes only.** It should not be treated as an official city service, tool, or complete representation of every park condition, amenity, closure, or maintenance issue. The project focuses on demonstrating how different information structures can be accessed, combined, and evaluated rather than providing a fully comprehensive parks platform.

The data sources may include incomplete records, outdated webpage content, inconsistent park identifiers, missing amenity descriptions, or formatting differences between several structures. Scraped content may break or become inaccurate if the webpage is redesigned or changed.

The product also has limitations in accessibility and portability. The current product may lack full screen reader support, mobile optimization, localization, or clear visual explanations for non-technical users. Future versions could improve documentation and provide exportable files so the product is easier to reuse in other tools.

## Ethics

Our ethical framework integrates several ethical frameworks as described in the open data ethics reading.

**Virtue Ethics:**  
The product emphasizes clarity, openness, and public usefulness by combining multiple data structures to make Seattle Parks information easier to understand and reuse.

**Consequential Ethics:**  
The product can help users explore park features and understand public data formats, but users may misinterpret the data as complete, current, or official. Disclaimers, source notes, and limitation documentation help reduce this risk.

**Non-Consequential Ethics:**  
The product respects public data responsibilities by avoiding personal data collection, citing sources clearly, and using responsible scraping practices that preserve the meaning of the original data.

## Societal Impact
This product supports public access to local park information by making scattered Seattle Parks data easier to view, compare, and reuse. It can help users understand park amenities while showing how public data becomes more useful when it is structured, documented, and portable.

However, users may mistake the combined data or visualizations as complete, current, or official. This could affect decisions about which parks to visit, especially for users who rely on accurate information about accessibility, facilities, or amenities.

Future improvements should focus on clearer documentation, accessibility, source transparency, and portability. This could include update dates, download options, data dictionaries, screen reader friendly labels, and notes when data is missing, outdated, or transformed.
